# Flappy Bird

A simple Flappy Bird game implementation in Python using Pygame. Test your reflexes and see how many pipes you can navigate through!

## 🎮 Gameplay

Control a yellow bird and navigate it through gaps between green pipes. The bird falls due to gravity, and you must tap the spacebar to make it jump. Each pipe you successfully pass increases your score by 1. The game ends if you collide with a pipe, the ground, or the ceiling.

## 📋 Requirements

- Python 3.7 or higher
- Pygame 2.0 or higher
